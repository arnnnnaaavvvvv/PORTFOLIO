## ⚡ Overview

A high-performance personal portfolio built with **Next.js 14 (App Router)**, **TypeScript**, **Framer Motion**, and **Lenis**. Designed with an architectural aesthetic inspired by modern creative agencies:
- **Obsidian Palette:** `#0d1117` base, `#11151d` elevated card layers, `#232a36` hairline structural borders.
- **Amber Gold Accent:** `#d8a94e` single-accent precision highlight.
- **Typography:** Space Grotesk (display), Inter (body/narrative), JetBrains Mono (data/tags).
- **Motion:** Quintic ease-out curves (`cubic-bezier(0.16, 1, 0.3, 1)`), zero spring/bounce easing, full Lenis momentum smooth scroll, custom magnetic trailing cursor.

## 🛠️ Getting Started

### Prerequisites
* Node.js 18.17+ or Node.js 20+
* npm or pnpm

### Installation
```bash
git clone https://github.com/arnnnnaaavvvvv/PORTFOLIO.git
cd PORTFOLIO
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run start
```
