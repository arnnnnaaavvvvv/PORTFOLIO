# Component Prototypes & Experimental Variants

This folder contains experimental Framer Motion and React component prototypes created during initial UI explorations:
- **`About.tsx`**: Experimental grid-based about layout.
- **`Contact.tsx`**: Standalone framer-motion interactive contact form.
- **`CursorDot.tsx`**: Lightweight React-based magnetic trailing cursor experiment.
- **`Header.tsx`**: Standalone scroll-spy navigation header.
- **`Hero.tsx`**: Standalone hero variant with title reveal.
- **`Hero3DPhoto.tsx`**: Three-dimensional tilt card variant.
- **`Magnetic.tsx`**: Spring-physics magnetic wrapper component.
- **`PageTransition.tsx`**: Curtain-reveal route transition effect.
- **`ProjectRow.tsx`**: Horizontal project list item variant.
- **`SmoothScrollProvider.tsx`**: React context wrapper for Lenis.
- **`VisionShowcaseSection.tsx`**: Multi-slide vision showcase variant.

The active production portfolio renders the modular components located directly in `src/components/` orchestrated via `src/app/page.tsx`.
